
# SAP-Style Employee & Payroll System

A full-stack enterprise application built with Java and Spring Boot to manage employee records and automate payroll processing.

## Tech Stack
* **Backend:** Java, Spring Boot
* **Database:** MySQL
* **Tools:** REST APIs, SQL, Maven

## Key Features
* Manages employee profiles, department allocations, and automated payroll computations.
* Built on a normalized relational schema with complex SQL queries (JOINs, subqueries, and aggregate functions).
* Fully unit-tested modules to ensure computational accuracy and data integrity across accounting records.

## How to Run
1. Clone the repository: `git clone https://github.com/2311Srajan/SAP-Style-Employee-Payroll-System.git`
2. Configure MySQL database settings in `application.properties`.
3. Build and run using Maven: `./mvnw spring-boot:run`
